# App ideas

Candidate apps for the hub, in the house style: **toys first, lessons smuggled
in**. "HomeOfEd" carries a double meaning - home of Ed, and home ed(ucation) -
and every idea here must honour both: a toy someone returns to because it is
fun, where a skillset develops as a side effect. Education is never the pitch.

## The bar

An idea belongs here when:

- **The play is the product.** The one-line description mentions no learning
  goal. If the fun disappears when you remove the lesson, it fails.
- **The skill is needed to play, not taught before playing.** The Poly Bridge
  test: you learn structural triangles because your bridge keeps collapsing,
  not because a tutorial explains trusses.
- **It fits the hub's shape.** Single screen by default, canvas-friendly,
  calm/tactile aesthetic, stateless-first (localStorage; a DB is additive -
  ADR 0008), copy base `templates/starter`, subdomain-routed.
- **It covers a skill gap.** Current coverage: rhythm (boop), letters/numbers
  (fridge), vocabulary (wotd), physics + emergence (silt, boids), geometry as
  art (karesansui), drawing (espy, mosa), safe AI use (sprout), nurture and
  responsibility (orbi).

## Seeds (not yet written up)

- **Estimation jar** - a daily "how many?" carnival guess (boids? magnets?
  sweets?); number sense and orders of magnitude.
- **Orrery** - drag planets, feel orbital speed vs distance; overlaps
  karesansui's rosette aesthetic, so needs its own angle first.
- **Anagram forge** - fridge magnets meet a daily letter set; word-building.
  Probably a fridge mode, not an app.
- **Clock garden** - something that makes analogue time tactile without being
  a clock lesson; no play-first angle found yet.

## Prior art worth stealing from

- [Zoombinis](https://en.wikipedia.org/wiki/Zoombinis) - set theory and logic
  disguised as escorting little creatures; the genre's high-water mark.
- Poly Bridge / World of Goo - structural engineering via collapse comedy.
- Turing Tumble - mechanical logic gates as a marble toy.
- [Sandboxels](http://stman.io/sandboxels-where-element-games-meet-infinite-simulation/) -
  what silt already knows: reactions invite experiments.
- [turtleSpaces](https://turtlespaces.org/) / [Turtletoy](https://turtletoy.net/) -
  Logo's turtle, still the best on-ramp to code-as-drawing.
- The [stealth learning framing](https://screenwiseapp.com/guides/educational-games-that-don-t-feel-like-school):
  "the work is the game; to win, you have to master the system."
