artwork/trumpet.svg, artwork/double-bass.svg, artwork/piano.svg
  Drawn in this repo - original work, no third-party source, no licence and no
  attribution owed, the same standing as the synthesized sounds below (not the
  four sourced ones, which are CC BY 3.0). Agent-drawn SVG is
  what the pitched-lane grill session settled on (spec §9, ticket 05) and Ed
  approves them by eye before the roster activates.

  They match the sourced set by construction, because the app tints every icon
  through mask-image and a mask only sees the filled area: one
  viewBox="0 0 512 512", one currentColor path, flat silhouette, no strokes,
  no embedded raster and no external reference. Interior detail is negative
  space - subpaths wound against the body so they read as holes.

    trumpet.svg     - side view, bell flaring right: leadpipe and mouthpiece at
                      the left, three valve casings and finger buttons on top,
                      the tuning-slide loop hanging under the tube.
    double-bass.svg - upright bass stood on its endpin: scrolled head with four
                      tuning pegs, long neck, violin-family body cut with two
                      f-holes and the bridge line between them.
    piano.svg       - grand piano from above: the wing-shaped case with the
                      open-lid line following the bent side, and a seven-key
                      keyboard along the front edge.

  Nothing in kit.json references these three yet. The pitched roster activates
  in ticket 10; until then they are files on disk and nothing user-visible
  changes.

sounds/marimba.wav, sounds/trumpet.wav, sounds/piano.wav, sounds/doublebass.wav
  Real instrument recordings, CC BY 3.0 - the pitched lane's four root samples
  (ticket 14). Attribution is required for these four; the other nineteen
  voices below are synthesized here and owe none.

  Source: nbrosowsky/tonejs-instruments
  (github.com/nbrosowsky/tonejs-instruments), whose own LICENSE.md releases its
  samples under CC BY 3.0 (creativecommons.org/licenses/by/3.0/) while the
  library code is MIT. Its sample-source-info.txt names the upstream recording
  for every instrument, and all four used here are the same one:

    Versilian Studios Chamber Orchestra 2, Community Edition ("VSCO2 CE"),
    by Versilian Studios - vis.versilstudios.net/vsco-community.html

  Per-sample provenance (upstream path -> shipped file), read from the
  repository on 2026-09-19:

    samples/xylophone/G4.wav  -> marimba.wav     VSCO2 CE, xylophone
    samples/trumpet/G4.wav    -> trumpet.wav     VSCO2 CE, trumpet
    samples/piano/G3.wav      -> piano.wav       VSCO2 CE, piano
    samples/contrabass/C2.wav -> doublebass.wav  VSCO2 CE, contrabass

  The kit ships what upstream ships: 44.1 kHz mono 16-bit WAV, so there is no
  decode and no resample. What was changed is the envelope and, for one file,
  the pitch - `apps/boop/scripts/sourceInstrumentSamples.mjs` holds the exact
  recipe and docs/adr/0065 the reasoning:

    marimba    - xylophone G4, cut to 390 ms. A struck bar is already a
                 one-shot, so nothing but the cut and a 40 ms release.
                 Our instrument is named Marimba and the library has only a
                 xylophone; pitched down to a C4..C5 lane it reads closer to
                 a marimba than to a concert xylophone.
    trumpet    - trumpet G4, 340 ms. 70 ms of the natural note, then a 48 dB
                 exponential fall and an 80 ms release. The source is a flat
                 7.2 s sustain with no decay of its own, so the whole envelope
                 is imposed: this is a staccato note, not a held one.
    piano      - piano G3, 320 ms. 45 ms held, 46 dB fall, 70 ms release - the
                 real hammer and string, damped early.
    doublebass - contrabass C2 transposed up 7 semitones to G2, 360 ms. Every
                 contrabass upstream is bowed, not plucked, and there is no G2
                 among them; C2 is the fastest-blooming note in the set and
                 the transpose shortens its bloom to 80 ms, which `holdMs`
                 keeps whole so the onset is the real bow.

  All four are normalised to the same 0.5 per-voice peak as everything else.

  These four are Marimba (in the shipped roster) and the three the pitched
  roster activates in ticket 10. Marimba's file changed with them: it moved
  from a synthesized C5 to a real G4, which is what puts every lane in C major
  (ADR 0065, superseding ADR 0059's F). Nothing else in the kit moved.

sounds/*.wav - the other nineteen
  Synthesized in this repo - original work, no third-party audio, no
  attribution owed. Real CC0-sourced one-shots were the first choice (per the
  ticket's sourcing guidance) but weren't reachable from this environment at
  the time. That record is kept because it is why these nineteen are
  synthesized, and the blocker on the four above turned out to be a different
  one: CC BY 3.0 audio, which is fine as long as it is credited:

    - freesound.org: search/browse works without auth, but every sound's
      actual audio file (including CC0-licensed ones, e.g.
      people/deadrobotmusic/sounds/737300 "Lil Lofi Snare 9", CC0) sits behind
      a login-gated download endpoint - confirmed by fetching the download URL
      directly, which returns the HTML login page rather than audio data, no
      API token available in this environment.
    - opengameart.org "CC0 Sound Effects": browsed the pack; no kick / snare /
      hi-hat / tom / marimba-ish / synth-hit content in it - mostly retro UI
      bleeps, creature and ambience sounds.
    - kenney.nl audio packs: CC0 and directly downloadable, but built for UI /
      sci-fi / RPG sound effects, not tuned percussive or pitched one-shots -
      using them would misrepresent the instruments in the design brief.

  Every voice in the kit, sourced or synthesized, shares one per-voice budget:
  normalised to peak 0.5 (the shaker deliberately sits under that, per the
  spec's "quieter than the hat") and under 400 ms, no long tails. Verified by
  apps/boop/src/engine/kitLevels.test.ts - duration, per-voice peak, the
  200 bpm 16th-note retrigger check, and the dense-hit sums (the classic six
  land at ~1.81 raw, the whole roster at 3.301 on a solid 200 bpm train; that
  figure is what MASTER_GAIN is sized against, and ADR 0065 records why the
  real xylophone raised it from 2.97).

  The classic five that remain synthesized (ticket 18; marimba was the sixth
  and is a real recording now):

    kick    - sine pitch sweep 150→48 Hz + a 20ms noise click for attack.
    snare   - noise body + two short tonal snaps (330→210 Hz, 200→170 Hz).
    hat     - three inharmonic high partials + a touch of high-passed noise,
              for a metallic tick rather than plain hiss.
    tom     - sine pitch sweep 200→85 Hz, longer and lower than the kick.
    boop    - two slightly detuned sine sweeps (660→520 Hz, 666→524 Hz) for a
              chorused, electronic, cheeky character.

  The fourteen new voices (ticket 01), rendered by the committed generator
  apps/boop/scripts/generatePlaceholderSamples.mjs:

    Drums
      clap      - three staggered high-passed noise bursts (0 / 9 / 18 ms) over
                  a short noise body: one seed re-struck, 909-style.
      shaker    - a soft high-passed noise pair (0 / 30 ms), scaled to 0.55 of
                  the per-voice peak so it sits under the hat.
      cowbell   - two inharmonic mid partials (540 Hz + 800 Hz), fast decay.
      woodblock - a resonant 1.15 kHz tick with a 4 ms noise click transient.
      triangle  - a high inharmonic stack (4.2 / 5.75 / 7.3 kHz), shimmery,
                  260 ms.
      cymbal    - bright high-passed noise across 390 ms, the longest tail the
                  400 ms cap allows (spec §10.3). Its decay is set by the
                  retrigger rule, not the length: slower tails measured 1.74x
                  at 200 bpm, because even incoherent noise sums in power over
                  eight overlapping hits.

    Notes
      bass      - a ~90 Hz sine pluck (96→88 Hz) with a quiet 180 Hz snap: the
                  low anchor the kit lacked.
      bell      - glockenspiel-ish: C6 (1046.5 Hz) + an inharmonic 2.89 kHz
                  partial, above the marimba's register.
      chime     - three stacked partials (1.57 / 2.35 / 3.14 kHz) under a 30 ms
                  raised-cosine attack, so it arrives softly.
      pluck     - harmonics 330 / 660 / 990 / 1320 Hz with staggered decays, so
                  the tone brightens then dulls like a plucked string.

    Silly
      boing     - a springy vibrato voice (320→150 Hz glide, 17 Hz wobble at
                  30% depth) - the generator's new vibrato block.
      pop       - a 40 ms upward blip (380→1100 Hz), bubble-wrap.
      zap       - a 2 kHz→200 Hz laser sweep in 140 ms.
      drip      - an upward water-drop chirp (620→1700 Hz) with a splash tick.

  The pitched lane's root samples were synthesized here too, at first (ticket
  04): trumpet C5, piano C4, doublebass C3, each a C because the ensemble was
  then in F major. Ticket 14 replaced all three with the real recordings at the
  top of this file, and marimba with them, so those recipes are history now -
  they stay in the generator, unbuilt, and ADR 0059 holds the reasoning that
  ADR 0065 superseded.

  `doublebass` remains a **separate instrument** from `bass`, whatever their
  sources: bass is the electric-ish 90 Hz pluck, stays one-note and stays
  synthesized, so saved boops using it keep sounding the same. Its artwork is
  artwork/guitar-bass-head.svg; doublebass keeps artwork/double-bass.svg.
  Do not merge the two.

  trumpet, piano and doublebass reached kit.json in ticket 10, which flagged
  them and marimba `pitched` on ADR 0065's registers (ADR 0067). marimba's file
  had already changed in ticket 14, which is the one user-audible thing that
  ticket did on its own.

  The generator's `voices` map holds twenty-three definitions, but a bare run
  rebuilds only the fourteen it still matches; see its header for which nine it
  does not and why. The recipes above are the record of what shipped.
