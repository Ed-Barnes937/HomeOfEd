sounds/*.wav
  Synthesized in this repo — original work, no third-party audio, no
  attribution owed. Real CC0-sourced one-shots were the first choice (per the
  ticket's sourcing guidance) but weren't reachable from this environment:

    - freesound.org: search/browse works without auth, but every sound's
      actual audio file (including CC0-licensed ones, e.g.
      people/deadrobotmusic/sounds/737300 "Lil Lofi Snare 9", CC0) sits behind
      a login-gated download endpoint — confirmed by fetching the download URL
      directly, which returns the HTML login page rather than audio data, no
      API token available in this environment.
    - opengameart.org "CC0 Sound Effects": browsed the pack; no kick / snare /
      hi-hat / tom / marimba-ish / synth-hit content in it — mostly retro UI
      bleeps, creature and ambience sounds.
    - kenney.nl audio packs: CC0 and directly downloadable, but built for UI /
      sci-fi / RPG sound effects, not tuned percussive or pitched one-shots —
      using them would misrepresent the instruments in the design brief.

  Six voices synthesized with the same gain-staging budget as the ticket-12
  placeholder generator (apps/boop/scripts/generatePlaceholderSamples.mjs:
  peak 0.5 per voice), which combine to ~1.83 raw in the worst case — the
  same combined figure apps/boop/src/engine/toneAudioDriver.ts's
  MASTER_GAIN/Limiter comment was tuned against. Verified by
  apps/boop/src/engine/kitLevels.test.ts (peak, duration and 200bpm
  16th-note retrigger checks).

    kick    — sine pitch sweep 150→48 Hz + a 20ms noise click for attack.
    snare   — noise body + two short tonal snaps (330→210 Hz, 200→170 Hz).
    hat     — three inharmonic high partials + a touch of high-passed noise,
              for a metallic tick rather than plain hiss.
    tom     — sine pitch sweep 200→85 Hz, longer and lower than the kick.
    marimba — fundamental (C5, 523.25 Hz) + a bright overtone + a 15ms click
              for mallet attack.
    boop    — two slightly detuned sine sweeps (660→520 Hz, 666→524 Hz) for a
              chorused, electronic, cheeky character.

  No third-party audio. The generator script itself lives outside the kit
  data path (apps/boop/public/kits/launch/**) that this ticket is scoped to,
  so it wasn't committed here; apps/boop/src/engine/kitLevels.test.ts is the
  durable, committed check on the claims above.
